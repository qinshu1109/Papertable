# ADR-008: 判决簿是 Papertable 的耐久层

- 状态: accepted
- 日期: 2026-07-29
- 来源: [用户确认](../sources/INPUT-20260729-001.md)

## 背景

改道会裁剪历史，也会丢失用户已经确认的否决和结论。

## 决策

只持久化用户确认的墓碑与金子。MemOS 是唯一真值，使用独立
`papertable-verdicts` Cube 和现有 HTTP MCP；Web 经 Node、桌面经 Rust，模型不接触
写接口。记录按项目隔离，固定 confirmed、排除 Brain/热记忆并锁定关键字段；正文为
最多 500 字的非空单行。重复确认幂等，修订只新增 supersede，注入只取链尾。MemOS
故障必须明确为不可用。

## 不变量

- proposed 不入簿，不自动晋级探索痕迹。
- 不新增本地判决表、删除能力、知识图谱或“掌握”模型。
