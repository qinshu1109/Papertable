# ADR-005: 宿主冻结作用域并双侧校验

- 状态: proposed
- 日期: 2026-07-28
- 来源: [INPUT-RAW](../sources/INPUT-RAW.md) 中 Fable-5 转述；待用户确认

## 背景
模型可写 scope 会破坏资料边界。

## 决策
宿主在本轮开始冻结“当前卡附件+项目绑定库”；模型只能传查询词。readableIds 在 TS 与 Rust 两侧校验，Rust 不信任前端。

## 不变量
- schema 无模型可写 scope/library。
- Rust 拒绝读取本轮未检索 chunk。

## 违反后果
模型可能越权读取材料。
