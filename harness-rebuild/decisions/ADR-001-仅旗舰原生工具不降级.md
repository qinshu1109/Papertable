# ADR-001: 仅使用旗舰原生工具模式

- 状态: accepted
- 日期: 2026-07-28
- 来源: [用户统一确认](../sources/INPUT-20260728-003.md)

## 背景

双阶段回退会掩盖协议故障并造成质量漂移。

## 决策

Agent 仅运行于通过三段握手的云端旗舰模型。失败即拒绝准入；修复保持同模型、同原生协议，不回落双阶段或宿主代搜。

## 不变量

- 用户路径无旧兜底调用。
- UI 显示具体失败段。

## 违反后果

故障会被伪装为正常回答。
