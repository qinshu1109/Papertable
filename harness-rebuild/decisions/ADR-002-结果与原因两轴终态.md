# ADR-002: 终态采用结果×原因两轴

- 状态: accepted
- 日期: 2026-07-28
- 来源: [用户统一确认](../sources/INPUT-20260728-003.md)

## 背景

平铺枚举不能同时表达结果与停止原因。

## 决策

结果：completed/partial/refused/failed/aborted。原因：预算耗尽、no_progress、protocol_error、user_abort、insufficient_evidence 或 none。拒绝非法组合；partial 只配耗尽或无进展，failed 配协议或未预期错误。

## 不变量

- 退出路径均合法。
- 终态可解释结果、原因、证据和预算。

## 违反后果

审计与续跑失去可靠依据。
