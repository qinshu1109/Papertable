# ADR-007: 协议修复按错误类别分流，仅允许确定性修复

- 状态: accepted
- 日期: 2026-07-28
- 来源: Codex 方案修正，用户认可

## 背景
统一"重试2次"会对 401 做无意义重试，对 429 缺退避；聚合网关可能污染协议。

## 决策
分类策略：401/配置错误不重试直接报错；429 退避后重试；5xx/断线/空响应有界重试（初始2次）；tool_call 参数畸形→确定性清洗（NFKC、零宽、全角标签）与无损重组，失败则要求同一模型重发合法调用；仍失败→重建流或同协议非流式请求→能力缓存失效重新握手→从最后稳定步骤重试；全部失败才进 protocol_error。
禁止：猜工具名、伪造 token、假装调用成功。修复动作全部记入事件流。

## 不变量
- 每类错误的处理路径可在测试中单独断言
- 任何修复步骤都不产生模型未真实输出的内容

## 违反后果
把网关故障洗成假成功，证据链失信。
