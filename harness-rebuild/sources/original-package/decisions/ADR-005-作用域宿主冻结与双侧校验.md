# ADR-005: 工具作用域由宿主冻结，readableIds 双侧校验

- 状态: accepted
- 日期: 2026-07-28
- 来源: Codex 方案修正，用户认可

## 背景
拖放附件引入 scope 概念后，若模型可传 scope 参数，等于把边界交给模型。

## 决策
search_notes 的可搜范围（当前卡片附件 + 项目绑定资料库）由宿主在本轮开始时冻结；模型只能传查询词。read_notes 的"先搜到才可读"（readableIds）校验必须同时存在于 TS 侧与 Rust 数据层，Rust 侧不信任前端。

## 不变量
- 工具 schema 中不存在模型可写的 scope/library 字段
- Rust 侧拒绝任何未出现在本轮检索结果中的 chunk 读取

## 违反后果
模型越权读取未授权材料，只读边界失守。
