# ADR-001: 仅支持云端旗舰原生工具模式，禁止降级

- 状态: accepted
- 日期: 2026-07-28
- 来源: 用户明确决定（2026-07-28 会话）

## 背景
双阶段模式目前是默认路径和所有探测失败的兜底，导致故障被静默掩盖、同会话答案质量漂移。

## 决策
Papertable Agent 模式只运行在通过三段握手探测的云端旗舰模型上。探测失败=该模型不可进入 Agent 模式（显式准入拒绝）。协议异常必须围绕同一模型、同一原生工具协议修复，任何路径不得回落双阶段或宿主代搜。

## 不变量
- 用户路径中不存在 runTwoStage / planQueries / 宿主词法兜底的调用
- 探测失败时 UI 显示具体失败段，绝不静默换轨

## 违反后果
协议故障被伪装成正常回答，用户无法信任引用与证据链。
