# ADR-004: 引用资格与 sources-only 部分答案边界

- 状态: accepted
- 日期: 2026-07-28
- 来源: Codex 方案修正，用户认可

## 背景
轨迹节点（搜索/阅读步骤）将被持久化并可提升为卡片，需防止"搜索过某句话"被当作事实证据。

## 决策
事实引用 [[source:]] 只能指向实际读取的资料片段。轨迹节点可查看、恢复、提升内容，但不具引用资格。
sources-only 下允许部分答案的条件（全部满足）：至少实际读取一段与问题直接相关的材料；同一旗舰模型成功综合；答案只用已读材料；明确标注覆盖不完整。
必须拒答：只有搜索命中无真实读取；已读内容不相关；证据不足以支持最低结论。
证据已读但综合与修复全部失败 → 报协议错误（ADR-003），"探索没做完"≠"证据不足"。

## 不变量
- controlledCitations 逻辑保留并扩展到附件与幽灵来源
- 搜索元数据永不产生引用

## 违反后果
引用体系被轨迹污染，产品退化为不可信 RAG。
