# ADR-006: 过程事件溯源持久化，模型工作集与完整历史分离

- 状态: accepted
- 日期: 2026-07-28
- 来源: 用户决定（过程完整持久化、预算产品化）

## 背景
现状为纯内存中间态+一条摘要trace，崩溃即失忆，UI 从不渲染 trace。

## 决策
每个有意义步骤即时事务写入 SQLite（步骤级事件，不含逐token）：探索开始、请求搜索、搜索完成、请求读取、读取完成、重复调用发现、协议修复与重试、预算追加、最终综合、终态。
崩溃后从最后完整步骤续跑。续跑时压缩仅作用于发给模型的工作集，完整历史不删。工作集只含：用户原始目标、去重后已执行搜索、已读相关原文、已确认引用、未解决问题、上次停止原因、新增预算。
事件行携带 schema_version；旧 turn 保留为 legacy 只读，不回填。

## 不变量
- 完整过程供人审计；模型永不收到完整运行日志
- 事件写入与业务状态变更同事务，无半条记录

## 违反后果
续跑失真或上下文膨胀失控。
