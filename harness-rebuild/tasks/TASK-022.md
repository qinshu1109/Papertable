## 描述

解决最终综合阶段“几十秒一个字都不上屏”，但不牺牲协议和引用可靠性。当前
`src/lib/agent.ts` 以 `emitTokens: false` 缓冲整次最终综合，验证通过后才把 tokens
交给 `src/store.tsx`；如果直接改成 `true`，协议泄漏或需要修复的第一次回答会进入
`Turn.content` 并自动保存，因此不能直接打开现有持久化流。

本卡采用双层输出：

- 临时预览只存在于 Store 的内存 UI 状态，按每次综合 attempt 隔离，不属于
  `Card`、`Turn`、Dexie、SQLite 或导出格式；
- 正式 `Turn.content` 继续等待完整响应通过协议、空响应、长度和引用门禁，成功后再经
  现有 `AnswerGate`、`controlledCitations` 与持久化路径提交。

预览沿用哨兵闸门，并增量拦截完整协议标签及可能跨 chunk 的标签前缀；引用控制标记在
正式校验前不得被渲染成有效引用。第一次综合需要修复、用户停止、窗口崩溃或重载时，
立即清空预览，正式正文保持原值。探索轮输出继续黑盒，短小的确定性终局继续缓冲。

边界：不新增“快速模式”或设置项，不持久化未验证 token，不实现正文回滚协议，不减少
工具调用，不改普通无资料库聊天的现有安全流式路径。

执行模型必须实时回写本卡：开始前修改状态；每完成一个复选项立刻勾选并在“任务进度”
追加日期时间、结果和证据；任何泄漏用例失败、阻塞或重设计都要当场记录，禁止完工后
统一补日志。详细证据写入 `logs/TASK-022.md`；执行模型不得自行标记 `done`。
